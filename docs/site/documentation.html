What the Next Image Inherits

An artwork made by moving agents. A studio changed by model agents. An artist who decides how that process continues.

phygen is a studio for an evolving computer artwork. A model agent changes the code, the program makes a picture, and the result becomes a recorded version.

The model agent is an artificial intelligence system that can inspect the artwork and edit its program.

I began with a tree of competing variants and an automatic judge. The current design makes one child at each step and keeps every child that passes the program checks.

That change is the central story of this project. It connects the visible artwork, the design of the studio, and the question of where the artist acts.

01 / Inside the image

The Image Is a Shared Trail

Simulated agents: make the patternModel agent: changes the programArtist: sets the conditions

The artwork starts with a simulation inspired by physarum, a slime mold that forms transport networks. Small simulated agents sense a shared trail, turn, move, and deposit into that trail.

A deposit changes the image and changes what another agent encounters. The trail is both a surface for marks and a form of memory. Larger structures develop from these local exchanges.

This is not the same as particles following a shape that I have already drawn. The shared trail must remain the main cause of the visible forms.

A second kind of agent works outside the image. This model agent can change permitted parts of the artwork program. It changes the conditions that produce the pattern, not each mark by hand.

The apparatus is not fixed

Vilém Flusser's account of technical images offers a useful connection. The image comes from an apparatus and its program. Working with it means exploring the possibilities that program permits.

In phygen, the model can also change parts of the program. The work therefore includes two connected spaces: possible images and possible changes to their conditions.

The artist defines what must stay. Here, that identity is the shared-trail process. A different expression is welcome; a different simulation hidden behind the same appearance is not.

02 / How the studio changed

From Choosing a Winner to Recording a Change

The project passed through four designs. These are stages of one line of work, not four independent products.

The important difference is who chooses the next parent. The early designs asked a model to choose. The later designs continue from each new working version.

master

The judged tree

The first design made several variants from a selected parent. A separate model compared their pictures without seeing their code and chose a winner.

The artist supplied a direction and could start from a selected version. The tree retained the other variants, so the winner did not erase its alternatives.

The interface gave that idea a visible form. Related versions appeared around their parent, and the selected version had its own detail panel.

simple

Novelty is not the same as quality

The second design gave the studio more responsibility. It chose a parent from a small archive and wrote its own direction.

A candidate also had to differ from earlier work. The aim was to avoid repeating a familiar image while still asking for quality.

But difference and artistic interest are not the same judgment. The project record describes higher costs and winners that a person often did not prefer.

This was a lesson from this studio, not a general proof against model judges. It was enough to change the next design.

slotmachine

One child, then the next

The third design removed the judge, the competing variants, and the archive. Each step made one child from the newest working version.

A child that passed the program checks stayed in the chain. Keeping a version meant the process could continue, not that an artistic contest had been won.

The interface changed with the idea. A column of large cards replaced the tree. The viewer could follow successive changes instead of comparing competing branches.

behavior / current

The artist can intervene

The current design keeps the chain and adds more direct control. An artist can repair failed work, change kept work, or return the chain to an earlier point.

The artistic brief also becomes stricter. Each step must make a clear visual change while preserving the trail-based identity.

The system can continue without asking for aesthetic approval at every step. That is real autonomy, but it is not a claim that the system can define artistic value.

03 / Inside the studio

What Happens Between Two Images

Simulated agents: make the patternModel agent: changes the programArtist: sets the conditions

The model receives a copy of the newest working version, recent pictures, the run history, and the artistic brief. It changes that copy within the permitted files.

The program checks the result before keeping it. It saves the work and makes a picture from that saved copy. The next step starts from the new version.

These checks establish that a version meets the program's requirements. They do not establish that it is beautiful, original, or better than its parent.

The picture comes from a separate place

New artwork code is not trusted. The artwork runs separately from the controller's records and keys.

The program captures the image from that separate page. Isolation limits what new code can reach; it is not a promise of safety under every condition.

04 / Around the studio

The Brief Is an Artistic Decision

Simulated agents: make the patternModel agent: changes the programArtist: sets the conditions

Once the judge was gone, the brief became more important. A vague request for improvement could no longer rely on a later comparison to correct the direction.

The brief asks for differences in branching, connections, occupied regions, and the balance between dense and sparse paths. A new color alone is not enough.

It also asks for one clear artistic decision. Earlier effects are choices, not permanent requirements. Removing an effect can be more useful than adding another one.

This matters because the trail retains previous actions. A moving source can leave deposits across an area that was intended to remain empty.

The agent must consider the accumulated image, not only the current particle positions. The instructions follow the behavior of this material, not a general preference for simplicity.

Continuation is not consent. The next working version can become a parent without becoming a version the artist prefers.

Repair and revision are different

Repair starts from a failed attempt's own saved work. It aims to make that attempt run while retaining its artistic intent.

Aesthetic revision asks a different question: what should change in the image? Neither action should hide which earlier decision is being altered.

The artist can stop the process, inspect the chain, and decide where to intervene. These controls make autonomy usable without pretending that the brief specifies every future choice.

The system also records paid work. A spending limit applies only when configured; the record of cost is not itself a limit.

05 / Reading the work

The Lineage Is a Second Surface

A final image does not show what the model inherited or changed. The chain does. Each version connects a picture with its code, settings, intent, and recorded work.

Gilbert Simondon's attention to the becoming of technical objects offers another useful connection. I read this artwork through successive states, not only its finished appearance.

The previous version is material for the next one. Its history is therefore part of the work, not only an explanation added afterward.

The interface lets me compare the image with the agent's stated intention. That record shows actions and results. It is not a complete explanation of the model's reasoning.

Keep the work before making the picture

The studio saves a fixed copy of each published program. The picture comes from that copy, so the image refers to a specific version.

Later changes create a different copy. This keeps the relation between code and image available for inspection.

The record has a structure

The studio keeps different kinds of facts separately: artworks, versions, runs, work tasks, pictures, costs, and updates.

What the next image inherits

The useful framework has three connected levels. Simulated agents produce the pattern. Model agents change the program. The artist defines the conditions of continuation and the occasions for intervention.

The tree and the chain place judgment at different points. Neither removes the need to look. A still picture can show composition, but not prove good motion.

I no longer ask the studio to certify that the next image is better. I ask for a substantial change, a retained identity, and a record I can inspect.

The next image inherits earlier choices as well as code. Designing how those choices continue is part of the artwork.
